# 🇮🇳 BharatVPN - India State & City Location Tunnel

**100% Free Desktop VPN & Location Switcher for India (Zero Cloud / Zero VPS required)**

BharatVPN lets you route your Windows internet traffic through specific Indian States and Cities (e.g., Mumbai, Delhi NCR, Bangalore, Ahmedabad, Surat, Pune, Hyderabad, Kolkata, Chennai, Jaipur, Lucknow, etc.) without paying for any cloud VPS.

---

## 🚀 How to Run (1-Click)

1. **Option 1 (Easiest):** Simply double-click **`start_vpn.bat`**.
2. **Option 2 (Manual Terminal):**
   ```bash
   python vpn_engine.py
   ```
   Then open your browser and navigate to: **`http://127.0.0.1:4589`** (or open `index.html` directly).

---

## 🌟 Key Features

- 🇮🇳 **20+ Indian States & 50+ Cities**: Select any state and city from interactive dropdowns or the clickable India map radar.
- ⚡ **Auto-Health & Ping Tester**: Automatically tests latency and selects the lowest-latency working node.
- 🔄 **Live Public Harvester**: Continuously discovers fresh Indian open nodes and resolves their geographic State, City, and ISP.
- 🛡️ **Windows System Registry Switcher**: Automatically updates Windows system proxy settings upon 1-click connect, and restores direct internet upon disconnect.
- 📊 **Real-time Live HUD**: Displays real IP vs Masked IP, Live speed gauges, oscillating data wave canvas, and connection timer.
- 🎛️ **Custom Node Support**: Add and test your own custom Indian proxy/server IP and port directly.
